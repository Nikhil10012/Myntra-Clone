# Myntra Landing Page Clone

## Project Overview
This project is a clone of the Myntra landing page, created using HTML and CSS. The goal of this project is to replicate the design and layout of the Myntra landing page as closely as possible to enhance my skills in web development.

## Features
- Responsive design
- Header with navigation menu
- Hero section with promotional banner
- Product categories section
- Footer with useful links and contact information
